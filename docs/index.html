mitreden

Deutsch · English

Type a sentence, get an audio file back — and they all sound alike.

I am building this for my three-and-a-half-year-old daughter, who uses augmentative communication. mitreden is German for joining in a conversation.

Half a minute, sound on. The voice you hear is the one the program makes.

Why

People who use augmentative communication often speak through more than one device: a talker app on a tablet, a reading pen, single buttons. Each brings its own voice along. The same sentence then sounds like a different person depending on the device — and someone who is only just learning that these devices are their own voice notices immediately.

mitreden turns that around. The voice is chosen once, the sentences live in one place, and every device gets the same audio file.

I mostly use it for an Anybook Reader — a pen that plays audio from stickers. Its software only takes MP3, which is what mitreden writes by default. The same files go onto a talker, onto buttons, into whatever comes next.

Try it

Put one of these files into an empty folder and open it. It fetches mitreden, starts it, and opens your browser. Four voices are included, so it speaks straight away — no account, no key, nothing leaving your network.

macOS Windows Linux

Docker has to be installed — the file says so if it is not. On a Mac the first start needs right-click → Open, because the file came from the internet.

With a terminal it is one line:

docker run -d -p 8770:8770 -v "$PWD:/data" ghcr.io/steffipetaffy/mitreden:latest

Everything you write stays in that folder: sentences, audio files, settings. Nothing is sent anywhere unless you choose a cloud voice yourself.

What it is not

Not a talker, and no replacement for one. It is the workshop behind it: text in, audio files out, in the format your device understands. It has no login either — run it on your own network, not on the open internet.

A companion

bildhaft does the other half: type a German sentence, get a row of pictograms back, correct them, print them. Same sentence, seen twice — symbols there, a voice here, and what you export there can be read in here.

Same speech bubble, different colour. Same idea, too: bildhaft keeps symbol references rather than pictures, mitreden keeps sentences rather than audio, so either file still works for whoever you hand it to.
