mitreden

Deutsch · English

Ein Satz eingetippt, eine Audiodatei zurück — und alle klingen gleich.

Ich baue das für meine dreieinhalbjährige Tochter, die unterstützt kommuniziert.

Eine halbe Minute, mit Ton. Die Stimme, die du hörst, ist die, die das Programm erzeugt.

Wofür

Wer unterstützt kommuniziert, spricht oft nicht über ein Gerät, sondern über mehrere: eine Talker-App auf dem Tablet, einen Hörstift, einzelne Taster. Jedes bringt von sich aus eine eigene Stimme mit. Derselbe Satz klingt dann je nach Gerät wie eine andere Person — und wer gerade erst lernt, dass diese Geräte die eigene Stimme sind, merkt das sofort.

mitreden dreht das um. Die Stimme wird einmal festgelegt, die Sätze stehen an einer Stelle, und jedes Gerät bekommt dieselbe Audiodatei.

Ich benutze es vor allem für einen Anybook Reader — einen Stift, der Audiodateien über Aufkleber abspielt. Dessen Programm nimmt nur MP3, und genau das schreibt mitreden von Haus aus. Dieselben Dateien wandern auf einen Talker, auf Taster, auf das, was als Nächstes kommt.

Ausprobieren

Eine dieser Dateien in einen leeren Ordner legen und öffnen. Sie holt mitreden, startet es und öffnet den Browser. Vier Stimmen sind dabei, es spricht also sofort — ohne Konto, ohne Schlüssel, ohne dass etwas dein Netz verlässt.

macOS Windows Linux

Docker muss installiert sein — steht es nicht bereit, sagt die Datei es dir. Auf dem Mac braucht der erste Start Rechtsklick → Öffnen, weil die Datei aus dem Internet kommt.

Mit Terminal ist es eine Zeile:

docker run -d -p 8770:8770 -v "$PWD:/data" ghcr.io/steffipetaffy/mitreden:latest

Alles, was du schreibst, bleibt in diesem Ordner: Sätze, Audiodateien, Einstellungen. Es geht nichts irgendwohin, solange du nicht selbst eine Cloud-Stimme wählst.

Was es nicht ist

Kein Talker und kein Ersatz für einen. Es ist die Werkstatt dahinter: Text rein, Audiodateien raus, im Format, das dein Gerät versteht. Eine Anmeldung hat es auch nicht — lass es im eigenen Netz laufen, nicht im offenen Internet.

Ein Schwesterprojekt

bildhaft macht die andere Hälfte: deutschen Satz eintippen, eine Reihe Piktogramme zurückbekommen, korrigieren, ausdrucken. Derselbe Satz, zweimal gesehen: dort Symbole, hier eine Stimme.

Gleiche Sprechblase, andere Farbe. Und dasselbe Prinzip: bildhaft speichert Symbol-Verweise statt Bilder, mitreden speichert Sätze statt Audio — so funktioniert beides auch bei dem, der die Datei bekommt.
